# Compare Plans

These plans apply to the hosted HAF service. [Self-hosted mode](/self-hosting) includes all core
feature capabilities without a hosted subscription, with operator-owned infrastructure and external
services. Existing resource and safety limits still apply; see the self-hosting guide for details.

Free includes HAF Bot's core community, identity, moderation, and automation tools. Premium removes Free limits and unlocks features with higher processing or hosting costs. Premium Plus includes the same per-server features as Premium, but can cover up to three Discord servers and includes one shared White-Label Bot identity.

- **Plan Owner** — the HAF account that buys and manages the subscription.
- **Guild Assignment** — a Discord server selected to receive that subscription's paid features.
- **White-Label Bot** — a custom bot name and brand shared across the Plan Owner's assigned Premium Plus servers.

## Plan Overview

|                                   | Free                   | Premium                     | Premium Plus                                         |
| --------------------------------- | ---------------------- | --------------------------- | ---------------------------------------------------- |
| Standard price                    | $0                     | AU$4.99/month or AU$45/year | AU$8.99/month or AU$80/year                          |
| Servers receiving plan features   | No subscription needed | 1 assigned server           | Up to 3 assigned servers                             |
| Bot identity                      | HAF Bot                | HAF Bot                     | HAF Bot or one shared White-Label Bot identity       |
| White-Label Bot installations     | Not included           | Not included                | Any or all assigned servers under one name and brand |
| Managed object storage per server | 100 MB                 | 1 GB                        | 1 GB                                                 |

These are the standard subscription prices, with no launch-place limit. New and returning Plan
Owners can choose the current offer. Check [hafbot.xyz](https://hafbot.xyz) or Billing for the
current Stripe prices. Existing subscriptions continue at their existing Stripe price unless the
Plan Owner chooses a change in Billing.

::: tip Returning to Free
HAF keeps saved configuration and existing records. Paid-only processing stops, and Free quantity limits block new items when the server is already over the limit. Restoring a paid Guild Assignment reactivates the saved setup for new activity, but HAF does not process activity missed while the feature was inactive.
:::

Guild admins may set lower local limits for active Clans, members per Clan, and officers per Clan under **Admin Dashboard → Clan Management**. A local limit cannot raise the plan allowance. Leaving a field blank uses the plan maximum.

Lowering a limit does not remove existing Clans or members. It blocks additions until usage is below the configured limit.

Advanced Ticket tools include auto-replies and conditional replies, anonymous Ticket types, AI transcript summaries, creator-role restrictions, and configurable per-member creation limits and exclusions. Free Tickets can still notify a configured support role when a Ticket opens.

[Suggestions](/features/suggestions) is also included on every plan, with no HAF plan quantity limit.

[Commerce](/features/commerce) is a separate, restricted pilot, not a generally available paid-plan benefit. Buying Premium does not grant seller approval or enable production sales.
